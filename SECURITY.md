# Security Policy

## Reporting a Vulnerability

**Please do not open a GitHub issue or pull request for security vulnerabilities.**

Report security issues by e-mail to **info@voteit.se**. Include as much detail as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Affected versions (if known)

We aim to acknowledge reports within a few business days and will keep you informed as we work towards a fix. We ask that you give us reasonable time to address the issue before any public disclosure.
